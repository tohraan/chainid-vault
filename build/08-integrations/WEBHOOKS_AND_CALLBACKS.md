# Webhooks and Callbacks — N/A This Scope

No webhooks, no callback URLs, no server-to-server notifications anywhere in this build — there is no server (see `03-architecture/BACKEND_ARCHITECTURE.md`) and no external service to webhook to or from. The closest analog, on-chain event listening, is covered in `06-blockchain/INDEXING_AND_SYNC.md` and is a client-side subscription, not a webhook.
