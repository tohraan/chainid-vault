# ChainID Vault — Build Package

**If you're Claude Code and this is your first message on this project:** read `00-overview/README.md`, then `11-ai-agent/CLAUDE_CODE_INSTRUCTIONS.md`, then begin at `02-planning/PHASE_01.md`.

**If you're human and just want the tl;dr:** we're building a local-only demo (no backend, no database, no testnet — see `00-overview/PROJECT_CONTEXT.md` for why) proving 3 things live: admin mints an NFT asset to a registered identity, a non-admin's attempt to do the same is rejected BY THE SMART CONTRACT, and every action shows up in a live on-chain audit trail. Everything else from the original SIH pitch (DIDs, VCs, IPFS, Postgres) is documented as a future phase, not built now — see `01-product/OUT_OF_SCOPE.md` and `02-planning/DEVELOPMENT_ROADMAP.md`.
