# Deployment — N/A Beyond Local (This Scope)

There is no remote/cloud deployment in this build. "Deployment" here means deploying the smart contracts to the LOCAL Hardhat node, covered fully in `07-smart-contracts/DEPLOYMENT_STRATEGY.md` and `10-operations/LOCAL_DEVELOPMENT.md`. The frontend is run via `npm run dev` (Vite dev server), never built/deployed to a hosting service for this build.

## Future phases

Real deployment (frontend to Vercel/Netlify, contracts to a permissioned network or testnet) becomes relevant at `02-planning/DEVELOPMENT_ROADMAP.md` Phase 9 — not designed now.
